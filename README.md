# Aprendendo Python

Repositório de estudos e exercícios práticos desenvolvidos durante meu aprendizado de **Python**.

## Sobre

Aqui organizo pequenos programas e desafios para praticar lógica de programação e os fundamentos da linguagem. Os arquivos numerados representam exercícios realizados ao longo dos estudos.

## Como executar

1. Instale o [Python 3](https://www.python.org/downloads/).
2. Clone este repositório:
   ```bash
   git clone https://github.com/gustavocardosodasilva141-lab/Aprendendo-Python.git
   ```
3. Entre na pasta e execute um arquivo:
   ```bash
   python 003.py
   ```

Troque `003.py` pelo nome do exercício que deseja executar.
